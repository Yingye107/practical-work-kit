Practical Work Kit — Codex + Claude

In Codex, use the $skill-name shown below.
In Claude Code, use /practical-work-kit:skill-name.
In Claude chat, type / and select a skill from the plugin.
Select the skill, paste your material, and say what you need:

Check work: Use $check-my-work to check this result, identify gaps, and tell me what to fix first.
Challenge a plan: Use $challenge-my-plan to test this plan and recommend a more practical approach.
Shape an idea: Use $shape-my-idea to turn this idea into a direction within my time and resources.
Carry context: Use $carry-my-context to prepare a handoff I can paste into a new conversation.

Set the language and length you want. Pasted text is enough to start;
readable attachments and available tools can deepen a check.
Install the bundle or individual skills from one source, avoiding duplicates.
A handoff does not transfer old attachments or local files to another device.
Checks cover only the evidence actually available.
GitHub publishing is separate from public-directory approval by OpenAI or Anthropic.
See INSTALL.txt for installation and docs/EXAMPLES.md for worked examples.

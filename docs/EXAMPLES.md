# Four worked examples / 四個使用範例

These inputs and outputs are illustrative, not measured host benchmarks. The useful result can be shorter or longer depending on your material. Replace the example with your own information and remove secrets before sharing it.

## 1. Check a budget / 核對預算

**Request**

```text
使用 $check-my-work 核對這份活動預算，先說能不能用。
場地 3,000，材料 2,000，預算表總額 6,000。
我沒有提供收據，也還沒確認是否含稅。
```

**Useful answer**

> 總額需要修正：3,000＋2,000＝5,000，目前多了 1,000。這次只核對列示加總；收據与稅額尚未確認。先把總額改為 5,000，再確認這是否為含稅金額。

The check should identify the actual arithmetic error and say what remains unknown. It should not invent extra fees or demand an unrelated checklist.

## 2. Challenge a plan / 挑戰計畫

**Request**

```text
使用 $challenge-my-plan 挑戰這個計畫。
我想用四週開發一個完整時間管理 App，但還沒跟任何使用者聊過。
目標是確認自由工作者是否願意使用，每週只有六小時能做。
```

**Useful answer**

> 建議先縮小。最承重的假設是自由工作者真的需要你提出的排程方式；四週只有 24 小時，做完整 App 會把驗證排在後面。先做一個可操作的排程樣稿，讓幾位目標使用者帶自己的真實任務試用。若他們不願再次使用，先調整問題與流程，再投入開發。

The user can propose or change the test. A synthetic critique is not evidence of demand and is not an independent reviewer unless a separate reviewer actually participates.

## 3. Shape an idea / 產生內容方向

**Request**

```text
使用 $shape-my-idea 給我三個五分鐘影片標題。
主題：小工作桌整理。受眾：在家工作的初學者。
語氣友善，週末能拍完，不要做完整商業企劃。
```

**Useful answer**

> 1. 五分鐘，找回清爽工作桌
> 2. 小桌子也能工作順手：先整理這三樣
> 3. 從一張整理好的桌子開始

Three titles are the requested deliverable. The skill should not automatically create a funnel, publish the video, buy ads, or claim guaranteed views.

## 4. Carry context / 保存交接

**Request**

```text
使用 $carry-my-context 幫我換到新對話。
已決定：活動改到週六上午；預算總額修為 5,000。
已完成：邀請函草稿。原稿：「週六上午一起來整理工作桌！」
待確認：場地地址、是否含稅。
下一步：確認地址後完成邀請函；還沒有授權寄出。
```

**Useful answer**

> 目標：完成週六上午活動的邀請函。已決定週六上午舉辦，預算列示總额為 5,000。
>
> 保留原稿：「週六上午一起來整理工作桌！」場地地址與是否含稅尚未確認。
>
> 下一步：確認地址後完成邀請函。尚未寄出，也沒有寄出授權。若要核對原附件，需把附件一併帶到新對話。

The note preserves the actual draft and authorization boundary. It does not convert an old note into permission for external actions or claim files were transferred.

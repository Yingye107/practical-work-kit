# Privacy notice

Effective date: 2026-10-03

This notice covers Practical Work Kit, published by [YINGYE Studio](https://github.com/Yingye107), including its four bundled skills.

## When you use the skills

The installable package contains reusable instructions and reference material. It has no publisher-operated MCP server, account sign-in, background service, telemetry endpoint, or runtime script. The package does not automatically send a copy of your prompts, documents, files, or handoffs to the publisher.

Your AI host processes the content you provide under its own settings, terms, and privacy policy. The host may save conversations or files. Practical Work Kit does not control that retention or provide a separate confidentiality boundary.

The skills can use tools already available in your host when your request and permissions allow it. A connected tool or external service may receive the information needed for the action you authorize. Its own privacy policy applies. A document or handoff does not grant permission to share data or access other accounts.

## Support and security reports

If you open a [GitHub issue](https://github.com/Yingye107/practical-work-kit/issues), the maintainer receives the information you choose to include. Issues in this public repository are publicly visible. Share a minimal example with synthetic data; omit credentials, private transcripts, and unnecessary personal information.

Use [private vulnerability reporting](https://github.com/Yingye107/practical-work-kit/security/advisories/new) for a security report. GitHub processes reports and support messages under its own policies. Report access and retention are determined by GitHub and repository administration; this package does not impose a separate deletion schedule.

For a question about this package or a support message you submitted, use the repository's current support channel. Conversation or account data held by your AI host must be managed through that provider.

## Changes

Material changes to the package's data handling will be described in this notice and the changelog. Check the notice for the version you install. This notice describes the current skills-only package; it does not cover separately installed plugins or services.
